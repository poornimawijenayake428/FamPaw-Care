Help & Frequently Asked Questions

How do I start?

Choose Create Account to make a demo account, or use the sample account shown on the login page.

Where is my information saved?

Information is saved in this browser using local storage and is separated by account on this device. Clearing browser data can remove it. This demo does not sync data between devices.

How do I add a family member or pet?

Log in, open Family Members or Pets from the side menu, and use the Add button on that page.

How do reminders work?

Open Reminders to add and manage tasks. Vaccination reminders can also be created from the Vaccinations page.

Can I reset my password?

Use the Forgot Password link on the Login page. This demo changes the password locally; it does not send a reset email.
